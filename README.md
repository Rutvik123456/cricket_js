# 🏏 CrickGame

A simple, browser-based **Bat, Ball, Stump** game inspired by Rock-Paper-Scissors, complete with automatic score persistence.

---

## ✨ Features

- **Quick Gameplay:** Play instant rounds against a randomized computer opponent.
- **Persistent Scoreboard:** Automatically tracks and saves your **Win**, **Loss**, and **Tie** totals across page refreshes.
- **One-Click Reset:** Start fresh at any time using the **NEW GAME** button.

---

## 📖 How to Play

1. Pick **Bat**, **Ball**, or **Stump** by tapping a button.
2. The computer selects an option at random at the same time.
3. The winner is decided using classic Rock-Paper-Scissors logic:
   - **Bat** beats **Ball**
   - **Ball** beats **Stump**
   - **Stump** beats **Bat**
   - Matching choices result in a **Tie**.
4. Your **Win / Lost / Tie** totals are saved automatically, even if you refresh the page.
5. Click **NEW GAME** at any time to reset the scoreboard.
